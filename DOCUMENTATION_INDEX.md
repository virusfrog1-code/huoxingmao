## 🗂️ File Organization

```
Project Root/
├── DOCUMENTATION_INDEX.md         ← You are here
├── PROJECT_SUMMARY.md             ← Overview of everything
├── GETTING_STARTED.md             ← Quick launch guide
├── README.md                       ← Complete features
├── SETUP.md                        ← Detailed setup guide
├── GAME_ECONOMY.md                ← Game mechanics & formulas
│
└── artifacts/gnarp-meme-official/
    ├── README.md                  ← Quick reference (in project dir)
    ├── SETUP.md                   ← Setup in project context
    ├── package.json               ← Dependencies
    ├── vite.config.ts             ← Build config
    ├── tsconfig.json              ← TypeScript config
    │
    ├── src/
    │   ├── pages/                 ← 6 main pages
    │   ├── components/            ← Reusable components
    │   ├── game/                  ← Phaser game engine
    │   ├── hooks/                 ← Custom hooks
    │   ├── store/                 ← Zustand store
    │   ├── lib/                   ← Utilities
    │   ├── App.tsx                ← Router
    │   ├── main.tsx               ← Entry point
    │   └── index.css              ← Global styles
    │
    ├── public/
    │   ├── gnarp-mascot.jpg       ← Gnarp image (AI-generated)
    │   ├── favicon.svg
    │   ├── manifest.json          ← PWA config
    │   └── sw.js                  ← Service worker
    │
    └── dist/                      ← Build output (after pnpm build)
```
